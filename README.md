# YToxide
Another rust project for learning, this time its a more improved version of the tui I tried making in python: [subber2.0](https://github.com/jar3n/subber2.0).

The motivation here is that I am more partial to Rust over Python for making tuis and have ratatui experience with my version of rusty mines. 

## Goals:
- local subscription tracking
- not use the youtube api (so people dont need a developer account to use this)
- prevent youtube from infering data about you
